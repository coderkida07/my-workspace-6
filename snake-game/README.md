# 🐍 Snake Game

An improved browser-based Snake game built with plain HTML, CSS, and JavaScript.

## Features

- Arrow Keys and WASD controls
- Start, Pause/Resume, and Restart buttons
- Score and persistent high score
- Wall and self collision
- Food generation that avoids the snake
- Increasing speed as the score increases
- Responsive UI

## Run locally

No installation or server is required.

1. Download or clone the repository.
2. Open `snake-game/index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Press **Start**, or press an arrow/WASD key.

## Controls

- ↑ / W — Up
- ↓ / S — Down
- ← / A — Left
- → / D — Right
- Space — Pause/Resume
